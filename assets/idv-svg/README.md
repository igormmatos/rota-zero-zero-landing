# Biblioteca SVG — ROTA ZERO ZERO

Pacote consolidado da biblioteca vetorial da marca.

- Base: biblioteca SVG v1.0 (P0 + P1 + P2)
- Extensão: P3
- Total: **46 SVGs únicos**
- Arquivo: `rota-zero-zero_biblioteca-svg-v1.1.zip`

A extensão P3 complementa a biblioteca v1.0; nenhum dos 17 SVGs anteriores foi substituído. A documentação histórica das duas entregas foi preservada dentro do pacote em pastas separadas.

O consolidado mantém os componentes de marca, trilhas, nós, setas e ícones editoriais, além dos respectivos metadados e licenças. Arquivos binários auxiliares de fontes não foram incluídos no pacote consolidado, pois não são necessários para o uso dos SVGs.
